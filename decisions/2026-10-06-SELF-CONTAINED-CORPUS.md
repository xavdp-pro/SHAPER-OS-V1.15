# A self-contained framework corpus

Direction: **[MANDATE]** operator clarification, 6 October 2026.

## One repository contains the required frame

SHAPER OS V1.15 carries its own laws, engineering rules, boot and operating
contracts, definitions and functional-unit obligations. A human or agent must
not need another SHAPER OS edition, private dialogue, unpublished report or
existing implementation to understand the frame or begin an authorized build.
All required framework references resolve to documents in this repository.

This direction adopts the consolidated local [LAW](../LAW.md),
[RULES](../RULES.md) and their declared contract dependencies as this edition's
operational corpus. Preserve every applicable obligation and stable rule identity;
apply the current explicit construction, storage, bridge and security directions
within their stated scopes. Merely smoothing prose cannot remove an obligation.
The [governing map](../docs/GOVERNING-CORPUS.md) identifies the current owners.

## Intentions and contracts, without implementation

Bring the meaning and contracts into the framework, not an executable kit.
The construction agent generates application code, build material, manifests,
configuration, tests and evidence records in a separate realization workspace.
A missing recipe or existing code repository is not a prerequisite. The human's
mission and the local contracts provide the basis for that work.

Read the mandatory local corpus in full, follow its applicable local dependencies
and record actual reading coverage. A guide or summary does not replace law.
If a material requirement is missing, identify its owner and dependent action;
do not invent authority or turn an unrelated open question into a blanket stop.

## Changes and evidence

The current directions preserve nested universes, private MariaDB per functional
unit, generic cognition continuity and the selected reference adapter. DEV
execution remains fluid within the human mandate: design security from the start,
build functionally necessary protections, then finalize production controls with
the assembled application view and recheck its workflows. Runtime proof belongs
to each generated realization, not to the existence of these documents.

Existing deployed systems are not changed by consolidating documentation. Their
actual implementation and operating records remain evidence for their own work.
Historical editorial reports are optional context, never an entry requirement.
Detailed migration provenance and review inputs stay outside the generic corpus.
