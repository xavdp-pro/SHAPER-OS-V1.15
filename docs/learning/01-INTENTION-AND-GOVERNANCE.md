# 1. From intention to authorized action

Status: explanatory synthesis; not a replacement for unreconciled laws.
Prerequisites: [intent](../../INTENT.md), [reading contract](../READING-CONTRACT.md).
Sources: S01, S03, S04 and S06 in the [source map](../../review/SOURCE-MAP.md).

## In plain language

Agree what should improve and what must be preserved before acting. Then check
what really happened. Being able to do something is not permission to do it.

**[EXPLANATION S03: OS master sections 1, 5, 19 and 22]** The following teaching
prose explains those distinctions; it does not independently adopt runtime law.

## What is it?

SHAPER connects a desired result to a bounded action and a verified consequence.
It preserves the differences between observation, interpretation, hypothesis,
decision, action and result. An agent may understand a problem very well without
having permission to change the affected system.

## Why does it exist?

An objective alone does not define legitimate means. “Obtain an appointment”
does not authorize removing someone else's booking. “Update prices” does not
authorize rewriting already accepted quotations. Faster reasoning makes these
boundaries more important, not less.

A request also needs enough context: whose desired result, within which scope,
under which constraints, by when, and with what evidence? Routine actions already
inside a valid mandate need not ask the same permission repeatedly. Exceptions
must not silently expand that mandate.

## In practice

A supplier sends new prices. The human wants future quotations to use them while
preserving existing commitments. The agent separates the received file from its
interpretation, identifies the owning function, validates the intended effective
date and records what changes are permitted. It checks the result, not only the
submission of a task. Recurrence becomes automation only under a ratified
standing mandate with review and revocation conditions.

## What can fail?

A signal is mistaken for a cause; an assistant suggestion becomes an order;
repetition becomes implicit permission; a faster import damages historical
records; or an agent continues after it lacks authority or decisive information.
Distinguish unknown, unavailable, forbidden, infeasible and failed. “I cannot
observe it” does not mean “I know it but cannot disclose it.”

**[EXPLANATION S03: OS master section 5]** START, CHANGE and STOP are all legitimate choices. A safe stop, bounded test or
honest blocked result can be preferable to falsely declaring success. Urgency
does not grant new rights; endless analysis is not automatically responsible.

## How do we verify understanding?

Explain what the supplier request permits and forbids; identify which statements
are observations and which remain hypotheses. Name the actor who can change the
mandate and the evidence that would show success. If the only answer is “the
agent knows what to do,” the boundary is not understood.
