# The Framework Is Consulted, Not Carried

> **Intent Classification**: GENERIC INTENT (Universal / Parameterized Blueprint)

The constructor studies the rich framework, reasons about the requested universe and derives the narrow material a runtime agent needs. A running task does not receive the complete law, every design discussion or unrelated private history as its working prompt. More text is not a substitute for usable context.

## Three distinct responsibilities

* **Design:** understand the complete local foundation and affected specialist contracts, resolve the human intent, identify contradictions and derive role, jurisdiction, resources, invariants and expected evidence.
* **Act:** receive that prepared brief, current state, relevant tools and previous actions; perform the precise task with the actual capabilities attached to the harness. Refresh changed context and reconstruct lost continuity before further effects.
* **Supervise:** compare actual effects with intended outcomes from outside the producing run, record disagreements, repair through the parent and carry durable learning into source, tests and intent.

The derived brief includes mission, boundaries, relations, initial/current state, resources, authoritative instructions, already-completed and uncertain effects, success criteria and escalation conditions. Design conclusions become enforceable checks where possible, not merely exhortations to the model. A source document is evidence, not a new authority. Human mandate governs both design and action.

## What supervision evaluates

Supervision aligns **knowledge** (what the agent can actually establish), **responsibility** (the obligation it owns) and **control** (the means and authority it actually has). A responsibility without means is a dependency to resolve, not permission to invent control. Detect tensions and recurring loops from evidence, preserve provenance and compare patterns across runs. The parent/root owns changes to the acting brief; the acting agent cannot certify its own deep soundness or rewrite the structure that sustains it.

Before adding a design concept to live context, identify the concrete mechanism it produced: a test, schema, refusal condition, bounded response or escalation rule. “The whole text so the model remembers” does not satisfy this contract. The [operating qualification cases](../agent/OPERATING-CONTRACT.md#decision-hygiene-qualification) exercise the derived behavior.

## Recovery operations

**CORRECT** changes a known error in controlled source. **REPAIR** restores state that cannot simply be rebuilt. **REBUILD** replaces reproducible runtime from a known-good image. **QUARANTINE** removes suspect runtime from service and preserves it for inspection.

Close the cause before rebuilding compromised runtime. Reduce its authority, retain evidence, quarantine, diagnose, correct source, rebuild, test, obtain an independent counter-view, return to service, observe, then deliberately retire the suspect instance. The persistent volume is not disposable merely because the container is. An agent never repairs its own live vital infrastructure; the parent acts.

## Honest limits and learning

A narrow brief does not excuse incomplete design reading. Conversely, reading the full framework does not mean that an agent has tools, production permission or perfect memory. Record the design derivation and its owning contract so a replacement constructor can recover it. Retain exact action/check evidence in the owning unit's durable store, independently of provider conversation history.
