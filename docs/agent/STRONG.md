# Strong agent route

Purpose: reconstruct the system from principles and test its coherence across
scales. Start with the [board](../CONTEXT-INDEX.md). Read the same complete
foundation as the [medium agent](MEDIUM.md), plus the source
lineage and unresolved alternatives needed for systemic decisions.

**[EDITORIAL]** Follow the route-selection rule in the medium guide. Strong is
appropriate when scope or consequences are systemic; if needed sources are
missing, selecting strong does not make them known. Preserve the explicit gaps.

Derive consequences explicitly: name the premise, the relationship it creates,
the affected contracts and the evidence that could refute the conclusion. Check
whether a local improvement damages a neighboring unit, another universe or the
human's ability to understand and control the system.

Maintain distinct models of meaning, authority, functional dependency, data
ownership and physical deployment. Explain how they connect without treating
them as identical hierarchies. A powerful model is not automatically root.

The principal human-paired agent takes this systemic responsibility even when
using the medium route's explicit steps. It must know where every obligation
lives and understand the whole foundation before directing a realization.

## Comprehension exercise

Complete the [medium route's scenarios](MEDIUM.md). Then explain which principles
remain invariant if the implementation language, model provider, database or
hosting topology changes. Identify what must be re-qualified and what cannot
be concluded from an unchanged interface alone.

Examine the result from three perspectives: kernel/governance, human/organization,
and runtime/failure. Record an independent counter-view when available and say
when it was absent. A self-review never becomes independent by changing its
heading.

Use the [source map](../../review/SOURCE-MAP.md) to reconstruct why distinctions
were introduced, then the [scenario checks](../examples/COMPREHENSION-CHECKS.md)
to test their consequences. For each proposed change, name the owning document,
affected human explanation, agent obligation, realization contract and evidence
that could contradict the proposal. Strong synthesis must not compress away
those links or silently decide unresolved source conflicts.

learning path is achievable now; certifying the complete V1.15 is not yet justified.
